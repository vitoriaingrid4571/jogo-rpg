# Harry: 1.800 km até Blackwell

RPG narrativo de apocalipse zumbi, feito com HTML, CSS e JavaScript.

Harry, xerife de Harlow, Texas, atravessa os Estados Unidos para chegar a Blackwell, Ohio, onde a filha Maggie está internada. O sangue dela é RH null e pode ser a chave para a cura.

## Como jogar

Abra o `index.html` no navegador. Precisa de internet só para carregar as fontes.

## Arquivos

- `index.html`: a estrutura da página
- `style.css`: o visual
- `script.js`: a história, as escolhas e os finais

## Como funciona

São cinco etapas de viagem, cada uma com uma escolha que muda os dias restantes, os suprimentos e a confiança do Kaul. No fim, esses números decidem qual dos três finais você vê.
